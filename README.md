# Projeto da Faculdade — Sistema PDV

Este repositório contém um projeto acadêmico de um sistema de **PDV (Ponto de Venda)**, desenvolvido por etapas.

## Etapa atual: sistema de caixa

O arquivo `index.py` representa a primeira parte do sistema: o caixa da loja. Atualmente, ele permite:

- Registrar vendas;
- Informar o nome e o valor de um produto;
- Aplicar descontos percentuais;
- Validar descontos entre 0% e 100%;
- Exibir um relatório simples com a quantidade e o total de vendas do dia;
- Encerrar o caixa.

## Próximas etapas

O projeto será ampliado aos poucos, conforme as próximas partes forem desenvolvidas. A ideia é completar o back-end do PDV antes de criar a interface visual.

Funcionalidades previstas:

- Cadastro e gerenciamento de produtos;
- Controle de estoque;
- Cadastro de clientes;
- Histórico de vendas;
- Relatórios mais completos;
- Organização do sistema em módulos;
- Front-end para utilização do sistema após a finalização do back-end.

## Como executar

É necessário ter o Python instalado. No terminal, dentro da pasta do projeto, execute:

```bash
python index.py
```
